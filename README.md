# MEVN Student CRUD Application

A basic Student Management CRUD application using MongoDB, Express, Vue.js, and Node.js.

## Structure
- `backend/` - Express API, Mongoose model, MongoDB connection, and CRUD routes.
- `frontend/` - Vue 3 + Vite interface with Create, Edit, List, and Delete functionality.

## Run locally

### Backend
1. Open a terminal in `backend`.
2. Run `npm install`.
3. Configure `MONGODB_URI` in `.env`.
4. Run `npm run dev`.

Backend runs on `http://localhost:4000`.

### Frontend
1. Open another terminal in `frontend`.
2. Run `npm install`.
3. Run `npm run dev`.

Frontend runs on `http://localhost:8080`.
